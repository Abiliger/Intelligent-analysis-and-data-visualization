# Exploratory Data Analysis and Visualization

This project demonstrates exploratory data analysis (EDA) and visualization using Python.  
It includes statistical exploration, feature inspection, and visual representation of datasets related to **wine composition** and **climate change (CO₂ levels)**.

## 🧩 Key Tasks
- Import and structure datasets with Pandas  
- Calculate basic statistics (mean, skewness, kurtosis)  
- Build visualizations with Matplotlib and Seaborn  
- Compare feature relationships and trends  

## 📊 Tools and Libraries
`Python`, `NumPy`, `Pandas`, `Matplotlib`, `Seaborn`, `SciPy`, `Scikit-learn`
